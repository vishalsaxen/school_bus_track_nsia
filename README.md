# GiaZo Chalo School

A Capacitor-based Android app for North Star International Academy — lets parents/staff pick a bus (No. 1 or No. 3), then choose to view it either on Track.Letsgro's own page or as a live marker on Google Maps.

## What's in this project

- `www/` — the actual app: `index.html`, `app.js`, `config.js`. This is the source of truth for the UI; edit files here.
- `android/` — the native Android project, generated by Capacitor. Don't hand-edit the web files inside `android/app/src/main/assets/public/` — they get overwritten every time you run `npx cap sync`.
- `capacitor.config.ts` — app ID (`com.northstar.giazochaloschool`), app name, and web directory.
- `package.json` — Capacitor core, CLI, Android platform, and the Browser plugin (used to open Track.Letsgro links in the system browser).

## Requirements

- [Node.js](https://nodejs.org) (v18+)
- [Android Studio](https://developer.android.com/studio) (needed to actually build/run the Android app — this project can't be built from the command line alone unless you also install the Android SDK/command-line tools separately)

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Open the Android project in Android Studio:
   ```bash
   npx cap open android
   ```
   (Or manually open the `android/` folder in Android Studio.)
3. Let Android Studio finish its Gradle sync (first time can take a few minutes).
4. Run the app on an emulator or a connected device using the ▶ Run button in Android Studio.

## Making changes to the web UI

Whenever you edit `www/index.html`, `www/app.js`, or `www/config.js`, run:
```bash
npx cap sync android
```
This copies your changes into the native Android project. Then re-run the app from Android Studio to see them.

## Before you ship this for real

A few things to revisit before distributing this beyond your own testing:

1. **Google Maps API key restrictions** — right now, `config.js` has your key restricted (in Google Cloud Console) to specific website referrers for browser testing. For the native Android app, you'll want to add an **Android app restriction** instead (using this app's package name `com.northstar.giazochaloschool` and your signing certificate's SHA-1 fingerprint), since a compiled Android app doesn't send an HTTP referrer the way a browser does. Android Studio can show you the SHA-1 under Gradle → Tasks → android → signingReport.

2. **Letsgro's internal API** — the live-location endpoint (`api.letsgro.co/.../poll_position_public_tracking`) is not a documented public API; it's what their own tracking page calls internally. It works, but Letsgro could change or restrict it without notice since it isn't published for third-party use.

3. **App icon** — Capacitor scaffolds with a generic default icon. Replace the icons under `android/app/src/main/res/mipmap-*/` with your own before publishing (or use Android Studio's Image Asset tool: right-click `res` → New → Image Asset).

4. **Publishing to the Play Store** — this project currently builds a debug/unsigned APK. Publishing requires generating a signed release build (Android Studio → Build → Generate Signed Bundle/APK) and a Play Console developer account.

## Uploading to GitHub

This repo is set up to push as-is:
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin <your-repo-url>
git push -u origin main
```
`node_modules/` is excluded via `.gitignore` — anyone who clones this just needs to run `npm install` before opening the Android project.
